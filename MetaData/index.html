MetaData and anatomical location about each session

For each session, we have meta-data about recording locations:

exclude_area.xls: ROI definition File

Contains manually defined Regions of Interest (ROIs) for each session.

  • One row = one ROI
  • Single session may contain multiple ROIs (e.g., session 11 has object area at tip + unknown areas)

File Columns

Column Description Example Values
SesIdx Session number 11, 12, 13 ...
y1 ROI start position (shank coordinate) 1200 (μm)
y2 ROI end position (shank coordinate) 1800 (μm)
arealabel Area Label See full list below, with number corresponding to subject index
ROIIndex ROI identifier, index in AreaXYZ.xlsx 1, 2, ..
Category Category to generate Figure 2 F, O, B
Area IT or EVC IT, EVC

Area Label Key

  • MB: Middle body
  • AB: Anterior body
  • MF: Middle face
  • AF: Anterior face
  • MO: Middle object
  • MO1s1 and MO1s2 correspond to 2 subregions of MO1
  • AO: Anterior object
  • LPP: Lateral place patch
  • PITP: Posterior inferotemporal place patch
  • CLC: Central lateral color area
  • AMC: Anterior medial color area

AreaXYZ.xlsx: locations in NMT template

Contains registered locations of each area. Template file and registration pipeline can be found in AFNI document.

One row = one area

Column Description
AreaIDX ROI index, corresponding to 'ROIIndex' in exclude_area.xls
Subject Subject Index
R Right/Left, larger values indicate more rightward
A Anterior/Posterior, larger values indicate more anterior
S Superior/Inferior, larger values indicate more superior
Label Category label
