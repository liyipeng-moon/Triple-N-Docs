MonkeyLogic

We use a matlab-based software, MonkeyLogic for behavioral control.

Behavior Control

In our experiment, fixation control and image presentation runs in parallel. This is difficult to achieve with the original MonkeyLogic adapters, so we made modifications to some of the adapters. You can find our modified adapter and code here: PassiveViewing_in_ML.

We also thank Jaewon Hwang for developing this great software, and especially make photodiode to be TTL-triggerable (and so the ImageChanger), see details here.

SpikeGLX

We use SpikeGLX to collect neuronal and event data. We thank Bill Karsh, Jennifer Colonell, and friends from the Neuropixels Slack (now Discord channel) for all the discussions.
